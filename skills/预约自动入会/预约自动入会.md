# 预约自动入会（腾讯会议）完整规范

替用户完成「打开客户端 → 进入会议 → 闭麦 + 关摄像头」，全程不点按钮。

适用：用户转了会议邀请 / 只给了会议号 / 说「帮我入会」「打开那个会」，且要求顺手把麦和摄像头关掉。
不适用：查会议信息、取录制或纪要（那是另一类 API 的事，本 skill 只操作本地客户端窗口）。

原则：动手前先说一句「我将操作你本机的腾讯会议窗口」，拿到同意再动。

---

## 0. 运行环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| Python | 3.8+，**只用标准库**，无需 pip install |
| 客户端 | 腾讯会议 3.x（进程 `wemeetapp.exe`） |

所有命令都在本 skill 的 `scripts/` 目录下执行。`python` 不在 PATH 时用 `py`。

---

## 1. 两条路径，先判断走哪条

看客户端「会议」页的列表：

- **路径 A：预约会议** —— 列表里有这场会（待开始）
- **路径 B：输入会议号** —— 列表里没有，用户只给了会议号（最常见）

---

## 2. 路径 A：预约会议

1. `py win.py 腾讯会议` 置前（客户端常缩在托盘，`win.py` 会 `ShowWindow(9)` 恢复）
2. `py grab.py 腾讯会议 s.png` 截窗口，看列表里「待开始」的那一行
3. 点该会议行 → 右侧详情面板点「进入会议」
4. 若弹「请选择会议音频的接入方式」→ 点「使用电脑音频」
5. 进会后做 §4 的收尾校验

---

## 3. 路径 B：输入会议号

```bash
py win.py 腾讯会议            # 没窗口就用 URL 拉起：
cmd //c start "" "wemeet://page/join?meeting_code=123456789"
py win.py 腾讯会议 --wait 20

py grab.py 腾讯会议 s1.png     # 截主界面，量「加入会议」图标坐标
py click.py <x> <y> --title 腾讯会议
py grab.py 腾讯会议 s2.png     # 弹窗出现后再量输入框坐标

py click.py <input_x> <input_y> --title 腾讯会议
py type.py 123456789          # 纯数字，不受输入法影响
```

**已知坑**：`wemeet://page/join?meeting_code=xxx` 只是把主界面叫出来，**会议号不会预填**，参数形同虚设，仍要手动输入。

表单字段自上而下：会议号输入框 → 你的名称 → 「后续会议都使用此名称」→ 会议设置四项。

输入后输入框会自动格式化成 `123 456 789`，正常现象。

### 3.1 会议设置必须逐项核对

**不要相信默认值。** 同一台机器两次实测结果就不一样：一次摄像头和麦克风都没勾，另一次两项都被勾上了。

目标状态：

| 选项 | 目标 | 说明 |
| --- | --- | --- |
| 自动连接音频 | ☑ 勾上 | 勾了才会自动接音频 |
| 入会开启摄像头 | ☐ **不勾** | 勾了进来就是开摄像头 |
| 入会开启麦克风 | ☐ **不勾** | 勾了进来就是开麦 |
| 入会开启美颜 | 随意 | 不影响 |

复选框挤在一起、每个只有 ~16px，**点之前先 `crop.py` 放大确认当前状态，点完再截图复核**，不要凭上次的坐标连点。

名称框会预填上次用过的名字，保留即可。

### 3.2 点「加入会议」

会议号合法时底部「加入会议」按钮才由灰变蓝，**按钮变蓝是输入成功的判据**。

音频弹窗**不一定出现**：勾了「自动连接音频」时多数情况直接进会并已接好电脑音频；只有弹了「请选择会议音频的接入方式」才点「使用电脑音频」。没弹窗不代表没连上。

进会成功的标志：窗口标题变成「会议名 + 计时（如 00:05）」，中间显示参会者头像。

---

## 4. 收尾：确认闭麦 + 关视频

工具栏文字是**反向**的，别被图标颜色骗：

| 看到 | 含义 |
| --- | --- |
| 「解除静音」+ 红斜杠 | 麦克风**已关** ✔ |
| 「开启视频」+ 红斜杠 | 摄像头**已关** ✔ |
| 「静音」无斜杠 | 麦克风**开着** ✘ |
| 「停止视频」无斜杠 | 摄像头**开着** ✘ |

不替用户开麦、开摄像头，除非明确要求。

### 4.1 关麦 / 关视频的三级优先级（不可颠倒）

**第一级：入会前在表单里勾掉**（见 §3.1）。这是唯一能保证"一进来就是闭麦关摄像头"的地方，能在这解决就不要进会再补。

**第二级：进会后点工具栏按钮。**

沉浸式/宫格全屏布局下底栏会自动隐藏，截图前先把鼠标移到窗口底部悬停 1.5~2 秒让它浮出：

```python
py -c "import ctypes; ctypes.windll.user32.SetCursorPos(960, 1040)"
```

然后「静音」点一下变「解除静音」、「停止视频」点一下变「开启视频」。

**第三级：点不到才用快捷键。**

前提是**会议窗口必须在前台**——前台是别的程序时按键会被它吃掉，实测完全无反应；窗口被遮挡时会议还会缩成右上角的悬浮小窗，按键同样打不到。

```bash
py win.py 快速会议          # 按会议名置前（会中标题不含「腾讯会议」）
py key.py alt v             # 开/关视频
py key.py alt m             # 静音 / 解除静音
```

**不管走哪一级，做完必须检查**：悬停底部 1.5~2 秒 → 截图 → 确认显示「解除静音」「开启视频」。别凭点击手感判断。

等待时间 1.5~2 秒即可；机器慢时等太久反而容易叠操作、坐标越点越偏，但**每次点击后仍要重新截图**再定下一步坐标。

## 5. 常见坑

1. **会中窗口标题不含「腾讯会议」**：入会后标题是「会议名 + 计时」或「免费版会议 00:05」。此时 `win.py 腾讯会议` 可能命中客户端主界面而不是会议窗口。按会议名片段找：`py win.py 快速会议`（把「快速会议」换成实际会议名片段）。
2. **工具栏自动隐藏**：不悬停就截图，底部是空白，找不到任何按钮。
3. **弹窗每次点击都会挪位**：一次点空导致整个「加入会议」弹窗上移约 110px，之后所有旧坐标作废。**点空就重截重算，不要连点。**
4. **全屏图不要目测坐标**：全屏图会被看图工具缩放，误差极大。一律 `grab.py` 截窗口（1:1），或 `crop.py` 裁小块。
5. **窗口被遮挡会缩成悬浮小窗**：右上角出现约 180×100 的迷你窗，主窗口 hwnd 还在、`IsWindowVisible` 也为真，但点击和按键都打不到，必须先置前。
6. **DPI 缩放**：脚本已内置 `SetProcessDpiAwareness(2)`。不设的话坐标会整体偏 20% 左右（125% 缩放时最典型）。
7. **快捷键不生效先看前台**：`py win.py <会议名>` 确认 `foreground =` 输出的是会议窗口。
8. **换机器必须重新量坐标**：分辨率、缩放、客户端版本、窗口大小都会变。

---

## 6. 安全约束

- 只操作本机客户端窗口，不调用任何会议 API、不改会议设置。
- 退出时用「离开会议」，**绝不用「结束会议」**（会解散别人的会议）。
- 不替用户开麦、开摄像头、共享屏幕。
- 不替用户改名字、改会议信息。
- 报告时说明：进了哪场会（会议号/主题）、当前是否闭麦、是否关摄像头。

## 7. 脚本清单

| 脚本 | 用途 |
| --- | --- |
| `winutil.py` | 共用底层：找窗口 / 抢前台 / 命中测试 / DPI 感知 |
| `pngio.py` | 纯标准库 PNG 读写、裁剪、缩放 |
| `win.py <片段> [--list] [--wait N]` | 列出窗口并置前 |
| `grab.py <片段>/full out.png [--scale N] [--screen]` | 窗口截图，1:1 PNG，打印 origin |
| `crop.py in.png x y w h out.png [scale]` | 裁剪 / 放大，用于量小尺寸控件（复选框只有 16px） |
| `click.py x y [--double] [--title 片段]` | 点击，带命中测试 |
| `type.py 123456789` | 输入会议号（纯数字） |
| `key.py alt v` / `key.py alt m` | 快捷键：开/关视频、静音/解除静音 |
| `paste.py "文本"` | 需要输入中文时用（如改名字） |
| `diff.py a.png b.png` | 像素差对比，判断点击后状态是否真的变了 |

## 8. 脱敏实测记录

一次完整入会（1920×1080 @125%）：

1. 客户端已在托盘，`win.py 腾讯会议` 无 hwnd 输出（不可见）→ `start wemeet://...` 拉起主界面；
2. 主界面「加入会议」图标 → 弹出表单；
3. 点会议号框 → `type.py 123456789` → 控件自动格式化；
4. 表单四项逐项核对，把「入会开启摄像头」「入会开启麦克风」点掉；
5. 点底部「加入会议」（此时才由灰变蓝）；
6. 直接进会，未弹音频选择（因为勾了自动连接音频）；
7. 悬停底部 2 秒 → 截图，确认显示「解除静音」「开启视频」。✅

经验：**快捷键先放最后**。同为官方快捷键，`Alt+V` 双向实测有效（关→开→关），`Alt+M` 机制相同；两者都必须会议窗口在前台。
